## 4. 사용된 경량화 기법

### 4.1 기법: GPTQ 4-bit Quantization

GPTQ(Generative Pre-trained Transformer Quantization)는 LLM을 위한 대표적인 Post-Training Quantization 기법입니다.

### 4.2 recipe.yaml 분석

```yaml
default_stage:
  default_modifiers:
    GPTQModifier:
      targets: [Linear]
      ignore: [embed_tokens, lm_head]
      scheme: W4A16
      block_size: 128
      dampening_frac: 0.01
      actorder: static
      offload_hessians: false
```

| 설정 | 값 | 설명 |
|------|-----|------|
| `GPTQModifier` | - | GPTQ 양자화 기법 사용 |
| `targets` | Linear | 모든 Linear 레이어에 적용 |
| `ignore` | embed_tokens, lm_head | 임베딩과 출력 레이어는 양자화 제외 |
| `scheme` | W4A16 | 가중치 4-bit, Activation 16-bit |
| `block_size` | 128 | 그룹 양자화 크기 |
| `dampening_frac` | 0.01 | Hessian 행렬 안정화 계수 |
| `actorder` | static | 정적 활성화 순서 |

### 4.3 config.json 양자화 설정

```json
"quantization_config": {
  "quant_method": "compressed-tensors",
  "format": "pack-quantized",
  "config_groups": {
    "group_0": {
      "weights": {
        "num_bits": 4,
        "strategy": "group",
        "group_size": 128,
        "symmetric": true,
        "type": "int"
      }
    }
  },
  "ignore": ["lm_head"]
}
```

| 설정 | 값 | 설명 |
|------|-----|------|
| `num_bits` | 4 | 4-bit 양자화 |
| `strategy` | group | 그룹 단위 양자화 |
| `group_size` | 128 | 128개 가중치마다 scale 적용 |
| `symmetric` | true | 대칭 양자화 사용 |

## 6. 개선 가능 방향

베이스라인을 뛰어넘기 위한 잠재적 접근법:

### 6.1 더 공격적인 양자화
- W3A16 또는 W2A16 시도
- Mixed-precision 양자화 (레이어별 다른 bit 적용)

### 6.2 다른 양자화 기법
- AWQ (Activation-aware Weight Quantization)
- GGUF/GGML 포맷
- bitsandbytes (NF4)

### 6.3 구조적 경량화
- Layer Pruning (레이어 수 감소)
- Width Pruning (hidden size 감소)
- Attention Head Pruning

### 6.4 추가 최적화
- Knowledge Distillation
- Sparsity 적용 (Sparse + Quantization)
