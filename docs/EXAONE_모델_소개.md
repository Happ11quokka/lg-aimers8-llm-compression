## 1. EXAONE 소개

### 1.1 EXAONE이란?

**EXAONE** = **EX**pert + **A**I for every**ONE**

- **1 exabyte** = 1,000 petabytes = 1M terabytes = 1B gigabytes = 10^18 bytes
- 인류가 이제까지 말한 모든 단어를 합친 언어 데이터의 양 = 약 5 exabytes

### 1.2 EXAONE의 철학

LG가 지향하는 **전문가 AI**는 『전문가에게 더 높은 전문가 역량을 제공』하는 것

| 구분 | General AI | Expert AI |
|------|------------|-----------|
| 목표 | 비전문가에게 낮은 수준의 전문 역량 제공 | 전문가에게 필요한 지식을 제공하여 높은 수준의 결과물 생성 |
| 활용 | 자료 초안 작성, 개념 이해 등 | 수만 명의 전문가가 협력해야 하는 분야에서 AI와 인간의 협력 |
| 우려 | 비숙련자 대체 우려 | - |

### 1.3 EXAONE의 발전 역사

| 버전 | 출시일 | 특징 |
|------|--------|------|
| EXAONE 1.0 | 2021.12 | 초기 버전 |
| EXAONE 2.0 | 2023.7 | - |
| EXAONE 3.0 | 2024.8 | - |
| EXAONE 3.5 | 2024.12 | - |

| EXAONE 4.0 | 2025.7 | Hybrid 모델 (추론 + 일반) |

## 2. 차세대 AI 혁명의 시작: Agentic AI

### 2.1 AI 발전의 흐름

```
Deep Learning → Generative AI → Agentic AI
```

### 2.2 생성형 AI vs Agentic AI

| 구분 | 생성형 AI | Agentic AI |
|------|----------|------------|
| 동작 방식 | 사전학습 데이터 기반 답변 생성 | 사람의 사고 과정을 AI가 학습해 수행 |
| 모달리티 | 텍스트부터 음성, 영상 등 멀티모달 수행 | 지시 없이도 자율적으로 판단 |
| 활용 | 콘텐츠 생성, 단위 업무 자동화 등 | 일상 생활과 산업에서 행동으로 현실화 |

## 5. EXAONE 4.0 - Hybrid 모델

### 5.1 개요

**"수학, 과학, 코딩 실력이 뛰어나면서, 일반 영역도 뛰어난 모델"**

- **추론 통합 Hybrid 모델**
- 전문 영역 지식 학습을 통한 전문성 강화
- Agentic AI를 구현하기 위한 다채로운 기능 설계

### 5.2 주요 특징
